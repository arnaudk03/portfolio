Diagramme de Séquence : Security OAuth2 & Keycloak Flow

Flux complet d'authentification centralisée et transmission de jetons JWT sécurisés.

1
User → Angular SPA

Connexion demandée (Auth Guard). Redirection vers le serveur Keycloak via OAuth2 PKCE Authorization Code Flow.

2
Keycloak IAM → Angular SPA

Authentification réussie. Émission d'un Access Token JWT signé RSA256 contenant les rôles de l'utilisateur.

3
Angular SPA → Spring Cloud Gateway

Requête HTTP envoyée avec l'en-tête Authorization: Bearer <JWT>. Validé à l'Edge par la Gateway.

4
Gateway → Microservices Spring Boot

Relai du jeton validé + injection de l'en-tête de corrélation X-Correlation-ID pour le tracing OpenTelemetry.

5
Microservice → RabbitMQ & PostgreSQL

Exécution des opérations métier isolées en base de données et émission d'événements asynchrones sécurisés.
